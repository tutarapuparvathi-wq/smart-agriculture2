# Smart Agriculture System

A farmer-friendly React website with:
- Phone number login
- OTP verification demo
- App-style dashboard
- Crop Care
- Weather
- Market Prices
- Farm Locations
- Responsive mobile layout

## Run in VS Code

Open the project folder in VS Code and run:

```bash
npm install
npm start
```

Then open the local URL shown by React.

## Demo OTP

This version uses a demo OTP so the UI can be tested without an SMS provider:

**123456**

For production, connect the OTP screen to a real backend/SMS service.

## Build for deployment

```bash
npm run build
```

The production files will be created in the `build` folder.
